## 지금 상태 (전부 라이브)
- **kzion.net/bt** 배포 완료. 로그인(목사님/관리자 PIN, PPT와 공유) → 주보 편집 → 미리보기·인쇄(트라이폴드 legal 6패널).

- 교인 명단 등 개인정보는 Supabase에만. repo엔 실명 0건(익명화 규칙 유지).

## 아키텍처 요점 (새 세션이 알아야 할 것)
- 코드: `bt/index.html`, `bt/js/{config,api,app,print}.js`, `bt/css/{bt,print}.css`
- **config.js = 공용 로직**: `buildOrderRows(S)`(예배순서), `autoNewsItems(S)`(교회소식 자동),
  `choirLine`, `orderTitleLabel`(직분), `saturdayOf`, `padTwoCharNames`/`nameSpans`(이름 정렬).
  app(편집)와 print(인쇄)가 **같은 함수**를 써서 "편집=인쇄" 일치.
- 서버: `supabase/functions/bt/index.ts` (563줄). getBulletin이 pastor/serve/love/events/meta/members/**choirSongs** 반환.
- 저장: `bulletin_inputs.data`(주보 전용, orderOverrides·news·autoNewsEdits·saturday·offering 등),
  로테이션은 `rotation_anchors`(앵커=이름) + `rotation_assignments`(오버라이드).
- 캐시 버스팅: bt 수정 시 `bt/index.html`의 `?v=NN` 올릴 것. 현재 css=v14, js=v13.
- 로컬 미리보기: `/tmp/kzion-preview`에 rsync 후 python http.server 8848 (구글드라이브 경로는 직접 서빙 불가).

## ⚠️ 아직 안 된 것 / 주의
1. **bt 함수 마지막 재배포는 사용자가 방금 성공**(choirSongs 포함). 앞으로 서버 또 고치면
   대시보드 붙여넣기 시 **파일이 길어(563줄) 중간에 잘리는 사고** 주의 — 붙여넣고 맨 끝이 `});`인지 확인.
2. **입력 칸 자동 늘어남 + 넘침(overflow) 감지·자동 축소**(컨셉 락 §6) 미구현. 이름 많은 주 대비.
   → 실제 PDF 뽑아보고 몇 명까지 한 장에 들어가는지 보고 기준 잡기로 함.
3. **PPT 페이지에 「주보」 탭 통합**(사용자 최종 요구: 한 페이지에서 다 하기) 미구현. 인쇄 검증 끝난 뒤 마지막에.
4. 실제 프린터 여백(가장자리 3~5mm 잘림) 실물 1장 확인 필요.
