담당자 PIN 관리

PIN 설정 · 변경

각 담당자에게 줄 PIN(숫자 4~8자리)을 설정합니다. 현재 값은 보안상 화면에 표시되지 않으며, 새 값을 입력해 설정을 누르면 즉시 바뀝니다. 설정한 PIN은 담당자에게 직접 전달하세요.

※ 이 기능이 동작하려면 setpin.sql 실행 + Edge Function api 재배포가 되어 있어야 합니다.
